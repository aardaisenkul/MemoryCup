# MemoryCup  

MemoryCup is a private memory collection app designed to help users create and store their cherished memories. Whether it's a personal journal entry or a shared memory with friends, MemoryCup provides a platform to capture moments in the form of text, images, or short posts.  

## Features  
- Create and manage personal memory posts.  
- Share memories with selected individuals or keep them private.  
- Support for text, images, and multimedia content.
